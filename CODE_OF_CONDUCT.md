# Community Code of Conduct

This project follows the
[Ansible Community Code of Conduct](https://docs.ansible.com/ansible/latest/community/code_of_conduct.html).
Please read it before participating in issues, pull requests, or forum
discussions.

Report unacceptable behavior through the channels described in the Ansible
Community Code of Conduct. Project maintainers may remove, edit, or reject
contributions and comments that do not follow it.
