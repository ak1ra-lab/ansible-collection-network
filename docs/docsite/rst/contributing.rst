Contributing
============

Development setup, the test matrix, and the Molecule workflow are documented in
the repository's `CONTRIBUTING.md
<https://github.com/ak1ra-lab/ansible-collection-network/blob/master/CONTRIBUTING.md>`_.

Common commands
---------------

.. code-block:: shell

   uv sync --group dev
   just lint          # ruff
   just typecheck     # mypy against the installed collection namespace
   just unit-test     # tox-ansible unit environment
   just ansible-lint
   just changelog-lint # antsibull-changelog fragment lint
   just docs-lint     # antsibull-docs lint-collection-docs
   just docs-build    # regenerate reference pages and build Sphinx

The docs recipes install the collection under test plus the local
``../ansible-collection-general`` checkout first, because the generated role
pages read the installed collection through ``ansible-doc``.

Documentation sources
---------------------

- Role contracts live in ``roles/<role>/meta/argument_specs.yml``; the role
  READMEs keep narrative and deployed-artifact details.
- Role reference pages are generated by ``antsibull-docs`` from the argument
  specs. Do not edit the generated ``*_role.rst`` pages by hand.
- Filter reference pages are generated from the plugins' ``DOCUMENTATION``
  blocks.
- Hand-written guides live under ``docs/docsite/rst/``.

Docs changes must pass ``just docs-lint`` and ``just docs-build``.
